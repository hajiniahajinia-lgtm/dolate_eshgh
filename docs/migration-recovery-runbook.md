# روند بازیابی مهاجرت نیمه‌اجرا

این دستورالعمل برای زمانی است که جدول `app_schema_migration_recovery` دارای نشانگر فعال باشد.

## قواعد توقف
- هیچ‌گاه نشانگر را صرفاً برای بازکردن مسیر اجرای مهاجرت پاک نکنید.
- تا پایان بررسی، اجرای `apply` و اجرای دستی SQLهای همان مهاجرت ممنوع است.
- بازگردانی transaction راهکار قابل اتکایی نیست؛ DDL در MySQL ممکن است پیش از خطا commit شده باشد.
- این فرایند فقط پس از تهیه backup معتبر از فایل‌ها و پایگاه داده انجام می‌شود.

## مراحل بررسی
1. با حالت `plan` وضعیت را بخوانید؛ وجود `recovery_required` به معنی توقف کامل است.
2. از ردیف نشانگر، نام و checksum مهاجرت، زمان شروع و `snapshot_json` پیش از اجرا را به‌صورت امن نگهداری کنید.
3. schema فعلی را فقط‌خواندنی از `information_schema` و registry فعلی را با snapshot مقایسه کنید؛ وجود جدول، ستون، ایندکس و تغییرات داده‌ای را بررسی کنید.
4. لاگ PHP/هاست و خطای SQL را بررسی و مشخص کنید آخرین statement موفق چه بوده است.
5. یکی از مسیرها را با تأیید مسئول پایگاه داده انتخاب کنید:
   - اگر هیچ statement اثر نگذاشته، پس از اثبات این موضوع می‌توان همان migration را از ابتدا اجرا کرد.
   - اگر بخشی اجرا شده، یک recovery migration مستقل و تکرارپذیر بسازید تا schema را به وضعیت مورد انتظار برساند؛ فایل تاریخی را تغییر ندهید.
   - اگر تغییرات داده‌ای غیرقابل‌تکرار یا نامطمئن‌اند، ابتدا داده‌ها را با backup و شواهد بررسی و اصلاح کنید؛ اجرای مجدد ممنوع می‌ماند.
6. پس از تکمیل recovery، نتیجه را با snapshot و schema مورد انتظار تطبیق دهید و migration را در registry با checksum اصلی ثبت کنید، فقط اگر اجرای کامل آن با شواهد ثابت شده باشد.
7. حذف نشانگر باید آخرین اقدام و همراه با ثبت گزارش بازیابی، تأیید مستقل و backup باشد. این نسخهٔ runner عمداً API برای حذف نشانگر ندارد؛ پاک‌سازی باید در عملیات کنترل‌شدهٔ جداگانه و پس از بازبینی انجام شود.
8. سپس دوباره `plan` اجرا و pending/mismatchها بررسی شوند. اجرای `apply` فقط با مجوز صریح انجام شود.

## محدودیت مهم
Snapshot فعلی ساختار جدول‌ها، ستون‌ها، ایندکس‌ها و registry را ثبت می‌کند؛ snapshot کامل داده‌های همه جدول‌ها یا backup جایگزین نیست. برای مهاجرت‌های data-changing، بررسی داده و backup مستقل الزامی است.
